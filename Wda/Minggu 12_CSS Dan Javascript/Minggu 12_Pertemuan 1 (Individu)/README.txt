PERPUSDIGITAL - TUGAS CSS MINGGU 12

Cara menjalankan:
1. Ekstrak folder tugas_css_minggu12.
2. Pastikan index.html dan style.css berada dalam folder yang sama.
3. Buka index.html menggunakan browser (Chrome, Firefox, atau Edge).

Contoh penerapan:
- External CSS: index.html memanggil style.css melalui <link rel="stylesheet" href="style.css">.
- Internal CSS: contoh dapat ditambahkan di dalam tag <style> pada bagian <head>.
- Inline CSS: contoh dapat ditambahkan langsung sebagai atribut style pada elemen HTML.

Contoh Inline:
<h2 style="color: navy; text-align: center;">Selamat Datang</h2>

Contoh Internal (di dalam <head>):
<style>
  h2 { color: navy; text-align: center; }
</style>

Catatan: Website utama menggunakan External CSS agar struktur HTML dan tampilan terpisah.
